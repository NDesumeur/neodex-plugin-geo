# Géo

Un quiz de géographie en pixel art : drapeaux, capitales et pays.

*English version: [README.en.md](README.en.md)*

## Les trois jeux

- **Drapeaux** : un drapeau s’affiche, trouve le pays.
- **Capitales** : trouve la capitale d’un pays.
- **Pays d’une capitale** : trouve le pays à partir de sa capitale.

Choisis le **monde entier** ou un continent : Europe, Afrique, Asie, Amérique du Nord (avec l’Amérique centrale et les Caraïbes), Amérique du Sud, Océanie.

## Commandes

- **1 à 4**, ou **flèches** puis **Entrée**, ou un clic.
- **Manette** : la croix ou le stick choisit, **A** valide.

## Comment ça marche

- Dix questions par série, quatre réponses prises sur le même continent.
- Les pays que tu rates **reviennent plus souvent**, jusqu’à ce que tu les trouves.
- Un record par jeu et par continent.

## Autorisations

- **Données** : tes records. **flagcdn.com** : les images des drapeaux (rien n’y est envoyé d’autre que le code du pays).

## Données et synchronisation

Tes records sont enregistrés par NeoDex, sauvegardés et synchronisés entre tes PC si la synchro est activée.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Géo → Installer**.
